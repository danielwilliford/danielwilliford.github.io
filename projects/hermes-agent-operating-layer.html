Hybrid model operations

Cost, quality, and latency are routing decisions.

Small local workers

Lightweight local models can handle bounded helper tasks such as classification, extraction, decomposition, formatting, recall, and artifact checks.

Local synthesis lanes

Larger local models handle synthesis, coding support, review passes, and multi worker consolidation when quality is sufficient.

Hosted API fallback

Hosted models remain useful for orchestration, difficult reasoning, high value synthesis, or continuity when local services are unavailable.

Measured routing

Routing map

A practical operating pattern for hybrid AI delivery.

The system separates bounded worker tasks, stronger reasoning, hosted fallback, deterministic gates, and human acceptance. A lead session owns the user conversation, kanban, acceptance criteria, and final review, then delegates scoped work to the cheapest reliable lane for the task. Small local models handle extraction, classification, formatting, retrieval, and artifact checks; larger local models or hosted APIs handle synthesis, repair, continuity, and harder reasoning. My current version routes across two local machines, but the pattern maps cleanly to secure corporate workers or hosted model APIs. Parallel routing is optimized to reduce wasted model spend and wall time while increasing auditable throughput.

Memory substrate

The substrate keeps agent context useful, bounded, and reviewable.

Role context flow

1Task enters any compatible harness.
2Role policy selects allowed memory, tools, and model lane.
3Retrieval checks project memory, vault notes, research ideas, and tool traces.
4Permission filters remove context the role should not see.
5The packet returns citations, blocked source ids, freshness labels, and review state.

Governance flow

1Profiles define role purpose, memory scope, and allowed tools.
2Substrate contracts keep Hermes, Pi Agent, Codex, and other runners interchangeable.
3Telemetry records retrieved sources, blocked sources, latency, tool calls, and accepted artifacts.
4Validation checks stale inputs, missing evidence, unsafe requests, and noisy context.
5Human acceptance owns user facing claims and operational changes.

Reduce context waste

Agents should not load every skill, note, memory, and tool for every task. Role scoped context lowers token spend and keeps small jobs from dragging unnecessary organizational history into the prompt.

Protect organizational knowledge

Retrieval is filtered before it reaches the model. Sensitive notes can appear as blocked source ids in telemetry without leaking the content into a worker lane.

Use the right runner

Local workers can handle extraction, recall, formatting, and artifact checks while stronger local or hosted models handle synthesis, repair, and difficult reasoning.

Benchmark and telemetry loop

The lab measures routing instead of treating parallelism as a feature.

Context window tuning

A scout benchmark moved CPU staging from an 8k context shape to a 65k context shape with parallel workers, resolving context limit failures and making helper output usable for longer evidence tasks.

A/B harness variants

Baseline, artifact DAG, verifier repair, small model parallel work, larger local synthesis, and hosted assisted variants are compared by output quality, repair burden, latency, and auditability.

Tool call telemetry

Tool traces expose which actions ran, whether outputs produced usable artifacts, where retries occurred, and which work should move to cheaper lanes.

Promotion rule

Routing patterns are promoted only when they improve auditable throughput without weakening tests, safety gates, source traceability, or final human ownership.

Delivery value

The agentic harness turns agent work into inspectable operations.

Profiles, allowed tools, routing policies, telemetry, and validation gates make agent behavior measurable enough for implementation work, not just demos.

  • Shows role scoped agent design without exposing prompt internals or sensitive retrieval state.
  • Shows cost aware routing across small local workers, larger local synthesis, and hosted API fallback.
  • Shows promotion discipline: patterns move forward only when telemetry improves throughput without weakening review quality.
  • Maps to enterprise AI work where delivery depends on governance, observability, and human owned acceptance.
